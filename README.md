# KhanijAI — Smart Governance & Compliance Monitoring System for Coal Mines

> **Every Mine. Every Compliance. One Intelligence.**

KhanijAI is a real-time AI governance and statutory compliance monitoring landing platform built for India's coal mining ecosystem (Coal India Ltd, DGMS CMR 2017, and state subsidiaries).

---

## 🌟 Key Features

- **Dynamic Framer Motion Choreography**: Fluid scroll-linked animations, parallax scaling, spring physics, and SVG dials.
- **Full-Screen Background & Embedded Monitor Videos**: Cinematic hero background and interactive desktop command center preview.
- **Horizontal Scroll Modules Track**: Apple-style 600vh pinned sticky horizontal scroll showcasing 10 core capability modules.
- **Predictive AI Engine**: Live typewriter terminal simulation demonstrating anomaly detection, statutory alerts, and real-time dispatch.
- **Interactive GIS Map**: SVG India coal basin map with 6 pulsing telemetry nodes and live inspection tooltips.
- **Three Operational Perspectives**: Sticky scroll mapped to Field Inspector, Mine Manager, and Regulatory Authority views with custom CSS mockups.
- **Arc Compliance Dial & Metrics**: Animated SVG gauge and verified statutory statistics.

---

## 🛠️ Tech Stack

- **Framework**: React 18 / Vite
- **Animation**: Framer Motion
- **Styling**: Tailwind CSS (Dark Coal theme with Molten Amber accents)
- **Typography**: Space Grotesk, Inter, JetBrains Mono

## 🚀 Getting Started

### Installation

```bash
# Clone the repository
git clone https://github.com/rushanadvani/coal-me-later.git
cd coal-me-later

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be running at `http://localhost:3000/`.
